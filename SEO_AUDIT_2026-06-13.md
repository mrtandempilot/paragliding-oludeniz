## 🚨 CRITICAL ISSUES (fix immediately)

### 1. Site is NOT indexed by Google
`site:paragliding-oludeniz.com` returns only a Dan.com "Domain for Sale" page.
None of the 104+ actual pages appear in Google's index.

**Why:** The domain was previously parked/listed on Dan.com. Google indexed that page. After the site went live (June 2026), Google hasn't re-crawled and indexed the real content yet.

**Fix:**
- Log into Google Search Console → Coverage → check for "Excluded" pages
- Submit sitemap: `https://paragliding-oludeniz.com/sitemap.xml`
- Use "URL Inspection" tool → Request Indexing for the homepage and 10 key pages
- Verify Google can crawl the site (fetch as Google for /en/tandem-paragliding)
- Check if Dan.com redirect/CNAME is fully removed at DNS level

---

### 2. Domain Rating = 0 (zero backlinks)
Ahrefs DR = 0. No referring domains. Google uses backlinks as a core ranking signal.

**Fix — backlink strategy:**
- List on Turkish tourism directories (GoTurkey, Turismo.org, Fethiye.com, oludeniz.com)
- Get listed on TripAdvisor as a service provider (backlink from high-DR site)
- Ask satisfied customers to mention the site on travel blogs/forums
- Create a Google Business Profile (free, high-authority backlink from maps.google.com)
- Reach out to travel bloggers who write about Ölüdeniz paragliding

## ⚠️ WARNINGS (fix soon)

### 3. Schema coverage: 12/104 pages (11.5%)
92 pages have zero structured data. Google uses schema for rich results (FAQ boxes, review stars, breadcrumbs).

**Pages WITH schema:** homepage, tandem-paragliding, blog articles, prices, book-now, transfers, acro-flights, cross-country, paramotor, pilot-services, training, sunset-flight

**Pages missing schema (priority order):**
- All tandem sub-pages (first-time, group-flights, safety-guide, faq)
- All babadag-guide sub-pages  
- weather-guide, thermals-guide pages
- about-us (Person/Organization schema missing)
- contact page (LocalBusiness schema missing)
- faq page (FAQPage schema missing — big Google rich result opportunity)

**Highest value fix: Add FAQPage schema to /faq page** → Google shows FAQ dropdowns in SERP which massively increases click-through rate.

---

### 4. FAQ page missing FAQPage schema
The /faq page has Q&A content but no `@type: "FAQPage"` schema. This is the easiest rich result to get.

**Fix:** Add JSON-LD FAQPage schema to `app/[locale]/faq/page.tsx`

---

### 5. No LocalBusiness schema on Contact/Homepage
Google Maps ranking and local SEO requires `LocalBusiness` schema with name, address, phone, GPS coordinates.

**Fix:** Add to homepage or layout:
```json
{
  "@type": "LocalBusiness",
  "name": "Paragliding Oludeniz",
  "address": { "@type": "PostalAddress", "addressLocality": "Ölüdeniz", "addressCountry": "TR" },
  "geo": { "@type": "GeoCoordinates", "latitude": 36.5504, "longitude": 29.1145 },
  "telephone": "+90-xxx-xxx-xxxx"
}
```
